# **Music-Kit-Card**

A simple and cheap to recreate musical toy, 8 keys , microcontroller and a passive buzzer .
Wanted to do this as a warmup for fabricate as i haven't done a project all summer, the only part i wanted to buy for it was the pcb, thats why its ghetto build with weird design choices.
## **Features:** 
 - Easy to build design, no smd components so you can even employ preschoolers for assembly.
 - Song recording and playback, you finally don't have to pirate fl studio
 - Cordless use, 18650 battery with a charging circut
 - Tone modification, go from bass heavy to high pitch alarm
